# FMG Med: website preview

Static preview of the fmg-med.ir website (medical thermography, Fanavaran Madoon Ghermez Co.),
built from a private repository and served by GitHub Pages at
https://soroush83faraz.github.io/fmg-med/

Pages carry `noindex`; the canonical site is https://fmg-med.ir. The quote form is not connected
in this preview. Medical thermography images are from Wikimedia Commons under free licences;
credits are on the Resources page.
